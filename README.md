# BABU
**Babu** is a voice-based digital personal assistant designed as a **loving family companion**, not a gadget.  It speaks primarily in **Hindi**, gently teaches **English**, supports **children’s learning**, helps **daily life**, and respects **elders with devotion**. 

**Babu listens, remembers, teaches, and cares.**
